# Keyva Beta 1.0.0

Android 12 or newer. Independent GPL-3.0 derivative of HeliBoard; licenses, source and credits retained.

- Traditional keyboard, languages, dictionaries, clipboard, emoji and themes inherited from HeliBoard.
- Android dictation, local recognition preference, selectable speech language and explicit provider consent.
- Optional selected-text Gemini correction, draft editing, preview, cancellation and guarded undo.
- Android Keystore encryption, sensitive/private-editor blocking and no input-bearing diagnostic logs.

Configure a newly issued Gemini key only in Ajustes IA, using a project without billing. Never reuse the previously exposed key. Quotas and model availability depend on Google; the conventional keyboard does not require Gemini.

Publication is gated on recorded real-service acceptance and successful CI. Consult docs/VALIDATION.md for exact tests and limitations. Model output can be incorrect: review before inserting. Speech language support depends on the installed provider and language packs. No proprietary glide library is included. Direct audio upload to Gemini and Liquid Glass styling are not included.
